# zHalfEdgeHandle

## zSpace::zHalfEdgeHandle

Declared in include/zspace/zCore/base/zDefinitions.h. Low-level math/storage reference; prefer geometry objects and function sets for application geometry.

An half edge handle struct to hold halfedge information of a half-edge data structure as indicies. Used mostly internally for array resizing.

version 0.0.3
