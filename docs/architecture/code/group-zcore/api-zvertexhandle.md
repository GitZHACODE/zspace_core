# zVertexHandle

## zSpace::zVertexHandle

Declared in include/zspace/zCore/base/zDefinitions.h. Low-level math/storage reference; prefer geometry objects and function sets for application geometry.

An vertex handle struct to hold vertex information of a half-edge data structure as indicies. Used mostly internally for array resizing.
