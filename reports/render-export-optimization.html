Changes

  • Fuse face-normal computation with ordered vertex-normal accumulation; preserve floating accumulation and normalization math. Keep the independent vertex-normal API.
  • Render export reads flat arrays by reference, reserves triangle output and reuses unique-edge direction/use counts/weights instead of copying arrays and building three ordered maps.
  • Remove the redundant post-smooth normal recomputation; keep the empty-mesh behavior and original ABI iteration clamp.
  • Migrate position lookup, directed edge vectors, face-local principal curvature and variable offsets to flat storage. Lookup preserves precision-six insertion, requested query precision, signed zero and last duplicate. Existing topology identity remains authoritative without creating topology.

Topology boundary

The migrated geometry paths do not create halfedges. Ordered vertex rings/incidence, vertex curvature/areas, edge face/boundary/dihedral queries, face adjacency, explicit halfedge APIs and local topology edits retain the lazy backend. Replacing ordered incidence and all SDK topology use remains incomplete; APIs and ID semantics are preserved.
