Changes

  • Replace smoothMesh tree nodes/repeated lookups with contiguous corner-edge records sorted by endpoints, face and corner. Preserve lexicographic edge-point numbering, ordered floating sums, duplicate-face handling, boundary neighbor order and first-two-face nonmanifold formula.
  • Generate output faces using per-corner edge-point indices. Move completed position/connectivity arrays into internal storage while retaining validation, default attributes and cache invalidation; public create/set APIs are unchanged.
  • Flat edge rebuild uses packed endpoint hash lookup, preserving first-face edge IDs, direction, use counts and endpoint-matched attributes; try_emplace avoids temporary nodes for shared-edge hits.
  • Add opt-in native/WASM phase instrumentation and an isolated actual-viewer stress page. Production runtime has profiling disabled; no viewer source, sketch, selection or display behavior changed.

Verification and limits

  • Native geometry/normal/connectivity/edge digests match for cube divisions 1–8, batch 8, curvature and exactly 500000 quads. Edge direction/local geometry digests also match.
  • Final isolated native Release build with profiling disabled passed; full isolated CTest passed 2/2 (core and IO smoke with OpenUSD disabled). Reordered-edge attributes/IDs/direction/use counts tested.
  • Repository-prescribed scripts/build.ps1 -Configuration Release passed; default build/ninja-msvc CTest passed 2/2 (core and IO smoke, optional OpenUSD disabled). Earlier dependency-block notes are historical; separate user-authored build/IO changes were preserved.
  • Production WASM build passed. Twelve output buffers byte-identical at 27 cube stages, three mixed/nonmanifold/repeated-corner cases before and after smoothing, and three 500000-quad grid trials. Float buffers finite.
  • Separate opt-in WASM profiling build passed byte parity against production. Timed phase values include instrumentation and are reported separately from production call medians.
  • Verified runtime installed and npm run build passed. Actual WebGPU viewer imported 125000 quads, smoothed to 500000, measured idle/brief wheel zoom, and verified undo/redo face counts.
  • Timings are exploratory, not universal speedups. Native phase measurements and production Node WASM timing have different scopes. Node WASM calls exclude JS transfer, history, UI and GPU rendering.
  • Storage installation still performs validation, initializes attributes and builds unique edges. Hash lookup still allocates nodes; reusable scratch or a node-free flat lookup remains a candidate.
  • Ordered adjacency/ring migration remains incomplete; explicit halfedge/local-edit contracts retain the backend.
  • Native verification uses the isolated OpenUSD-disabled configuration. Unrelated dirty OpenUSD/build/IO changes were preserved; this milestone does not validate USD or native OpenGL runtime.
  • Browser action timings are one run before/after, not medians. rAF gaps observe scheduling, not GPU completion. Camera input is a brief wheel-zoom burst within the sample, not continuous orbit. JS heap snapshots fluctuate with GC; they are not peak total/GPU memory.
